# Ight Bot legal site

This folder contains the public Privacy Policy and Terms of Service for Ight Bot.

- `index.html` - legal landing page
- `privacy.html` - Privacy Policy
- `terms.html` - Terms of Service
- `styles.css` - shared styling

The documents are intended to reflect Ight Bot's current production data practices as reviewed on October 9, 2026. In particular, the published privacy text must describe the deployed production behavior rather than staged or unreleased modernization changes. Update these documents whenever Ight Bot's data collection, retention, sharing, moderation, or platform behavior materially changes.

## GitHub Pages

This repository is public, so GitHub Pages can publish the site without exposing the private Ight Bot source repository. Configure Pages to deploy from the default branch/root. The legal site is located under the repository's GitHub Pages project URL at `/ight-bot/`.

Until the legal branch is merged into the branch used by GitHub Pages, the files remain available for review in GitHub but are not the published policy.
