# Ight Bot legal site

This folder contains the public Privacy Policy and Terms of Service for Ight Bot.

- `index.html` - legal landing page
- `privacy.html` - Privacy Policy
- `terms.html` - Terms of Service
- `styles.css` - shared styling

The documents are intended to reflect the bot's current implementation as reviewed on September 30, 2026. Update them whenever Ight Bot's data collection, retention, sharing, moderation, or platform behavior materially changes.

## GitHub Pages

This repository is public, so GitHub Pages can be enabled without a paid plan. In repository settings, configure Pages to deploy from the default branch/root. Once Pages is enabled, the legal site will be available under this repository's GitHub Pages project URL at `/ight-bot/`.

Until Pages is enabled, the files remain publicly viewable in this GitHub repository.
